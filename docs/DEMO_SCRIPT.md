# 🎬 DEMO SCRIPT
## Incident Memory Command Center - 60 Second Demo

**Goal**: Show judges how Hindsight memory makes the agent learn and improve

---

## 🎯 THE HOOK (5 seconds)

**Say**: "This AI agent learns from every incident it sees."

**Show**: Dashboard - Point to learning cycle visualization

---

## 📚 THE CONCEPT (15 seconds)

**Say**: "Here's how it works - five steps:"

**Point to each step on screen**:
1. **ANALYZE** - Current incident
2. **RECALL** - Search historical data  
3. **REASON** - Evidence-based analysis
4. **RESOLVE** - Fix the problem
5. **REMEMBER** - Store for next time

**Say**: "Each cycle makes it smarter."

---

## 🧠 THE MEMORY IN ACTION (30 seconds)

**Do**: Click "Analyze New Incident" → Use demo button "Database Connection Failed"

**Say**: "Let's analyze this database incident..."

**Wait**: ~10 seconds for analysis

**Point to**: **🧠 HINDSIGHT MEMORY section** (should be prominent with cyan border)

**Say**: "Watch this - it found 3 similar past incidents with documented resolutions."

**Point to historical incident cards**:
- "See incident INC-1001? It shows the root cause was connection pool exhaustion..."
- "The resolution that worked: increased pool size from 100 to 250..."
- "The outcome: latency improved from 8 seconds to 1 second."

**Say**: "This isn't generic advice - it's **proven solutions from our history**."

---

## 💾 THE REMEMBER PART (10 seconds)

**Do**: Scroll down, click "Resolve & Remember"

**Say**: "When I mark this resolved, it gets stored in Hindsight memory."

**Do**: Click submit (if time allows), or just point to button

**Say**: "The next similar incident will recall THIS solution. That's how it learns."

---

## 🎊 THE CLOSE (0 seconds)

**If time**: Show success screen with "🧠 LESSON RETAINED"

**Otherwise**: "Questions?"

---

## 🐛 TROUBLESHOOTING

### If No Historical Incidents Show
**Say**: "In this case, there's no exact match in memory yet - that's why you see the generic analysis warning. But once we resolve this, it will remember it for next time."

**Point to**: Yellow "Generic Analysis" warning box

### If Analysis Takes Long
**Say**: "It's searching through all historical incidents right now - notice it's using real Hindsight memory, not fake data."

### If Something Breaks
**Backup**: "Let me show you the Memory Explorer instead - here you can see all 79+ incidents it's already learned from..."
